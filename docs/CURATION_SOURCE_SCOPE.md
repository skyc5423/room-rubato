2026-11-12. The result cards previously offered no links to primary evidence even for facts already checked in RECOMMENDATION_COPY_REVIEW.md and RECOMMENDATION_FACT_CHECK_2026-11-12.md. This change exposes those existing reviewed sources for six stable curation IDs; it does not certify all catalogue items.

The optional native disclosure distinguishes each source's actual scope from Room Rubato's editorial suggestion: Xiph FLAC format and NIDCD noise risk; MoMA's specific Van Gogh work; Fritz's two blend descriptions, not the chocolate brands; SEC general bond risks, not Korean deposit rules or suitability; Apple's model-specific repair conditions; and Sony WH-1000XM5 as a counterexample to total noise removal, not all-headphone performance evidence. Links are deliberate user navigation with noopener/noreferrer, not embedded players, remote images or automatic requests. No answer, feedback, profile, scoring or persistence field changes. Unmapped examples render no source badge, rather than claiming evidence coverage they lack. Disclosure is optional so evidence does not overwhelm the main comparison task. The data is keyed by existing curation IDs, keeping evidence provenance separate from stored responses.

Synthetic tests verify IDs refer to existing examples, primary HTTPS links and claim limits, native collapsed disclosure, no embedded requests/storage, and no invented links for unreviewed examples. This is not live authenticated-result acceptance or a current-stock check.
