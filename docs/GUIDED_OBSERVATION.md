## UX scope

Optional collapsed artwork prompts ask for visible evidence, interpretation and whole/detail comparison. Institutional facts remain separate from Room Rubato editorial prompts. Completing a lesson does not require completing this optional activity.

Completed notebook entries open read-only. Exploring a slider or artwork does not overwrite their recorded answers. Explicit editing uses an in-memory draft; Save replaces the existing record, Cancel retains it. This is not a longitudinal history system. Existing completion timestamp is preserved. Drafts are owner-bound, cleared on successful deletion/cloud replacement, and checked against the latest stored same-record snapshot before commit to reject known cross-tab conflicts. Browser localStorage has no atomic compare-and-swap; simultaneous writes in separate tabs remain an architectural limitation, distinct from server revision protection.

The default diagram setting (60) and the recorded first-choice setting are separately labelled. Both original question wordings and recorded settings are shown on completed revisit, because differing prompts/settings confound any interpretation of changed answers. Specific slider labels and heading focus transitions improve navigation but do not substitute for real screen-reader/device testing.
