# Editorial production and return-value gate

This is a working editorial process, not a promise of scheduled publication. Nothing here enables auto-publishing, notifications, personal-data research or production deployment.

## When to commission content

Write one sentence naming the experience gap and the current place it occurs. A new topic must improve an existing visitor journey or a clearly identified missing conceptual distinction. A bigger lesson count, arbitrary daily streak or equal coverage of all questionnaire domains is not sufficient.

Choose one small outcome the visitor can perform: identify an edge, compare two layouts, distinguish sensory description from evaluation, or explain a changed observation. Do not promise increased aesthetic ability, personality accuracy or retention lift without appropriate evidence.

## Review gates

1. **Feasibility:** read the actual primary material. Search snippets, an inaccessible creator profile or a third-party compilation do not establish the original's teaching method or reuse rights. If unavailable, record the gap; use verified independent material without claiming it represents that creator.
2. **Evidence and rights:** map each factual claim to its source and each asset to its permission. Keep original interpretation visibly distinct. Describe contrary findings/corrections when relevant. Link is not permission to reproduce.
3. **Experience:** observe first, reveal a useful concept, try a bounded comparison, invite an optional next observation. Check the example actually changes the variable it claims to change. Keep disclosure proportionate, not a wall that hides the task.
4. **Natural Korean:** remove generic praise and unexplained labels; use concrete actions and examples. Do not erase necessary storage, scientific or sensory limitations to sound smoother.
5. **Accessibility and design:** keyboard control, focus continuity, reduced motion, non-audio alternative, narrow reflow, meaningful image/caption relationship. Inspect pixels as well as automated assertions.
6. **Integrity:** opening content does not invent answers/completions; saved notes remain unchanged; optional settings and temporary state are accurately disclosed. Use isolated synthetic fixtures only.
7. **Release:** code/content candidate needs aggregate CI and documented review. Current no-deploy instruction remains binding. Publication is not automatic because this checklist passes.

## Maintenance, without false freshness

At each proposed content release, check changed sources/rights and every changed destination. Keep a small correction log with the claim, correction and verification date. If a source fails, retain only claims that can still be supported; do not silently swap a different image or invent attribution. Existing daily rotation must continue to say it rotates existing material.

Do not announce a weekly or daily content cadence before there is a reviewed queue and operational capacity. A practical trial is one bounded item through the full process, followed by a capacity decision, not an unapproved recurring commitment. User notes/answers are not an editorial research dataset.
