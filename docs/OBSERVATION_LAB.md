# 관찰실: 2026-11-11 구현 검토

## 사용자에게 생긴 새 흐름
홈에서 로그인이나 설문 없이 /notes 진입 → 직접 SVG 조작 또는 수동 합성음 재생 → 첫 감상 선택(둘 다/모름 포함) → 전문 개념·관찰 질문·한계 → 재감상 → 자신의 이유 기록 → 저장함/내 기록/관련 활동/텍스트 내보내기.

8개 활동: 명암, 간격, 시선 연결, 동시색대비, 감정과 판단, 복잡성/처리 유창성, 선원근법, 싱코페이션.

## 근거와 사용권
- National Gallery 용어집: chiaroscuro, linear-perspective
- Exploratorium: color-contrast (그림/문장 복제하지 않음)
- PBS The Art Assignment / MoMA: 미니멀리즘. 일상의 단순함과 미술 운동 구분.
- Never Too Small: 특정 58㎡ 아파트 사례. 일반적 효용으로 확대하지 않음.
- Leder et al. 2004: 미적 감상 단계와 감정/판단 구분. 자체 활동 검증 아님.
- Reber et al. 2004: 처리 유창성 이론. 복잡성 선호에서 성격 추론 금지.
- Witek et al. 2014와 Senn et al. 2024: groove/싱코페이션의 상반된 결과 함께 제시. 중간 복잡성 선호를 정답 처리하지 않음.

모든 도식은 코드로 독자 제작. 합성음은 WebAudio sine oscillator이며 외부 음원·작품 이미지 사용 없음. 음성 자동재생 금지, 낮은 gain, 수동 정지/언마운트 정리.

## 저장 및 개인정보
- 기존 Supabase 프로필/점수에 연결하지 않음.
- localStorage의 계정 UUID별 key 또는 guest key에 감상 기록만 저장.
- 계정 전환 시 즉시 이전 owner의 내용 숨기고 새 key 로드.
- 기록은 해당 브라우저에만 존재하고 다른 기기 동기화 안 됨. UI에 명시.
- 설정값도 선택 때 함께 저장하여 그래픽 조건차이를 숨기지 않음.
- 손상 JSON 무시, localStorage 오류 안내, 텍스트 내보내기 제공.
- 신규 기록 형식 v1 및 콘텐츠 버전 저장.

## 확인
전체 44개 테스트 / typecheck / production build 통과.
새 테스트: 8활동 소스/연결/한계 체크, 기록 파싱, 덮어쓰지 않는 갱신, 완료 후 다음 추천, 전체 선택→해설→재선택→기록→재마운트 흐름, 계정 전환 격리.
실브라우저 시각/오디오 QA는 배포 후 필요.

## 아직 하지 않은 것
- 계정 간/기기 간 노트 동기화.
- 실제 작품/음원 감상 데이터로 척도 검증.
- 사용자 대상 리텐션 실험.
- 기존 프로필 JSONB 다기기 충돌 수정.
- 성격 분석의 정밀도를 높였다는 주장.
