# Observation return journey

2026-11-12. Source-only UX audit found a generic home entry and catalogue-order notebook CTA even when an observation was partly finished. This change makes existing research-grounded observation content easier to resume; it adds no questions or learning-efficacy claim.

Home chooses most recently updated started unfinished lesson, then bookmarked lesson, then recent completed lesson. It shows lesson title and completion count, not response choices or memo text. First-time entry leads directly to the two-artwork comparison; all activities and survey room remain available. Notebook's main CTA also prioritizes unfinished observations. Navigation consistently calls the area 관찰실.

All decisions run locally from the current owner's existing journal. No new schema, tracking, automatic writes, cloud request or research use of responses. Owner/readiness gating hides prior-owner summaries, and focus/pageshow/storage events refresh the snapshot. Unknown lessons are ignored and invalid dates sort to the end. Storage failures preserve browsing with an explicit notice.

Validation covers selection priorities, no-write render, hidden memo content, owner switching, hydration/storage failure, and context continuation instead of untouched light. Browser live QA remains separate from unit checks; do not claim actual375px verification without a supported viewport.
