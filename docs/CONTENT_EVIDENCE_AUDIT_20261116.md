## Follow-on: artwork context and physical scale

Read the six exact Met object pages 436535, 436105, 436121, 437853, 437881 and 45434, including the Vermeer audio transcript supporting edge-light claims, and the Met Open Access policy. Each object page currently marks its image Public Domain. Existing dates, credit lines and bounded Korean context match the institutional accounts; the uncertain Degas sitter remains explicitly uncertain. No new art image is imported.

A material display gap was found: the digital frames equalize very differently sized objects, while the individual caption claimed original color preservation. Add the catalogue's metric dimensions (height × width) to both individual and comparison captions, and replace the color guarantee with explicit screen-color/brightness/size limits. This helps separate an object's physical scale from its browser presentation without pretending to reproduce gallery viewing.
